## 境界データ（国土数値情報の行政区域）

`public/data/geo/` の地図の境界の出典と加工。生成は `bash pipeline/build_geometry.sh`（取得は `data/raw/n03` に保存。zip の原本はリポジトリに入れない）。

### 出典

- 国土交通省「国土数値情報（行政区域データ）」N03、2021年（令和3年）版（基準日：2021年1月1日）
- データページ：https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2021.html
- 取得元（都道府県ごとの zip、`<pp>` は 01〜47）：`https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2021/N03-20210101_<pp>_GML.zip`。各 zip の SHA256 と大きさは `pipeline/sources.json` の `n03` に記録し、取得のたびに照合する
- 原典資料：国土地理院「数値地図（国土基本情報）」の行政区画データ。座標系は JGD2011（B, L）。
- 2021年1月1日版を選んだのは、社人研の推計の基準（2020年の国勢調査）に最も近く、社人研の市区町村コードと1対1で合うため。後の版（例：2024年版は浜松市の区が再編後）では合わない地域がある

### 加工の内容（`pipeline/build_geometry.py`）

1. N03 は1つの地域が複数の図形（島など）に分かれて入っている。コード（N03_007）が同じ図形を1つにまとめた
2. **社人研の単位に合わせた**：政令指定都市は社人研が区を単位にしているので、区の境界のまま使った（市に統合しない）。東京23区も区のまま。福島県の浜通り13市町村（いわき市・相馬市・南相馬市・広野町・楢葉町・富岡町・川内村・大熊町・双葉町・浪江町・葛尾村・新地町・飯舘村）は1つにまとめ、社人研の「浜通り地域」のコード 07999 を付けた
3. 社人研に地域が無い図形（北方領土の6村、コードの無い所属未定地）は取り除いた。一覧と理由は `docs/geometry-reconcile.md`
4. 名前（`properties.name`）は社人研の名前（`index.json`）にそろえた。コードは5桁の文字列（先頭の0を保つ）
5. mapshaper（`npx mapshaper`）で簡略化した。図形の頂点を残す割合は、県の地図は5%から、全国の県の層は2%から始め、ファイルの大きさの上限（300KB。北海道と沖縄県は600KB）に入るまで段階的に下げた（隣り合う境界は同じ線を共有したまま簡略化し、小さな島も残す）。結果は下の表
6. TopoJSON の座標は1万分割の格子に丸めた（北海道で約70m、小さな県で約20m）
7. 国土数値情報は座標系が JGD2011 で、地図の座標（WGS84 の緯度経度）との差は1m未満のため、座標の変換はしていない

**注意**：この境界は地図表示のための粗い図形で、測量・面積の計算・行政区域の確認には使えない。海岸線と行政界は簡略化しており、実際の境界とは数十〜数百m以上ずれる所がある。

### 生成物と大きさ

| ファイル | 内容 | 大きさ |
|---|---|---|
| `public/data/geo/japan.topo.json` | 47都道府県（オブジェクト名 `prefectures`、`code` 2桁・`name`）。頂点の0.3%を残した | 247,692 bytes（上限300KB以内） |
| `public/data/geo/pref/<pp>.topo.json`（47ファイル） | 市区町村（オブジェクト名 `areas`、`code` 5桁・`name`）。45県は5%、岩手県と長崎県は4%を残した | 最小 16,094 bytes（滋賀県）、最大 332,090 bytes（北海道）、合計 4,717,797 bytes |

- 300KB を超えるのは北海道だけ（332,090 bytes。北海道と沖縄県は600KBまでを許した。沖縄県は169,088 bytes）。北海道以外で最大は長崎県の282,533 bytes（島が多い）
- 全国の県の層は、目安の2%では約1.25MBになるため、段階を下げて0.3%にした（247,692 bytes）。日本全体の絵なので海岸線は粗いが、県の形は分かる
- **小さな島**：簡略化の `keep-shapes` は、地域ごとに最低1つの図形を残すが、すべての小島を残すわけではない。N03 の約12万の図形（島・岩礁を1つずつ数えた数）のうち、市区町村の層に残るのは約4,900。面積別に見ると、1 km2 以上の図形は2,235個が2,232個に、0.1 km2 以上は2,815個が2,791個に、0.01 km2 以上は4,202個が3,812個になった。消えたのは主に0.01 km2（1万平方メートル）未満の岩礁
- 社人研の1,884地域は、すべて図形を持つ。簡略化の前後で面積が最も減ったのは利島村（残り96.6%）で、残りが98%未満になったのは3地域だけ（利島村、舟橋村、安堵町。いずれも96%以上が残る）
- 同じ県のなかの市区町村どうし、全国の層では県どうしが、同じ境界線を共有したまま簡略化している（隙間や重なりが出ない）。N03 は隣り合う境界の頂点が約1cmずれているため、読み込み時に `snap` で揃えた
- 再現：`bash pipeline/build_geometry.sh`（取得は SHA256 で照合。2回続けて実行して、全48ファイルがバイト単位で同じになることを確認した）

**注意**：この簡略化は地図表示用で、元の境界より粗い。社人研の数字の出典とは別に、画面と README に上の出典と加工の旨を書く（本節の「画面と README に書く文言（案）」を使う）。
