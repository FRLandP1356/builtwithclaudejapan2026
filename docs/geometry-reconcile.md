# 境界データと社人研の地域の突き合わせ

社人研（IPSS）の地域（`public/data/index.json` の1,884地域）と、国土数値情報の行政区域データ N03（2021年1月1日版）の市区町村コードを、両方向で突き合わせた結果。
この文書は `pipeline/check_codes.py` が読み、表のコードと実際の食い違いが1つでもずれるとテストとビルドが失敗する（`python3 -m pipeline.check_codes`）。

**結果の要約**

- N03 のコードは1,902種類。うち1,883件は社人研のコードと1対1で一致した。名前は1件（高知県梼原町）を除いて一致している。
- 社人研の地域で境界が無いものは **0件**（浜通り地域は、N03 の13市町村を1つにまとめて対応した。節 C）。
- 境界のうち社人研に地域が無いものは、**北方領土の6村**（節 B）と、**コードの無い所属未定地**（節 B）。どちらも地図から取り除いた。
- 政令指定都市の区と東京23区は、社人研が区を単位にしているので、N03 の区の境界をそのまま使った（市に合わせていない）。

## D. 名前の違い（コードは一致）

コードが一致していて名前の字だけ違うもの。地図の名前は社人研の表記を使う（`properties.name` は `index.json` の名前）ので、動作に影響はない。

| コード | 社人研 | N03 | 対応 |

| 39405 | 檮原町 | 梼原町 | 社人研の表記を使う |

## E. 境界の取り方（参考）

- 2021年1月1日版の N03 を使った。社人研（2020年の国勢調査が基準）の全地域とコードが食い違う地域は無かった（上記のとおり）。コードを変えない小さな境界変更までは照合していない。浜松市の区の再編（2024年）など、後の版で起きた変更は反映していない。
- 政令市の区のコードは N03 でも区ごとに分かれており、社人研の区の行（`kind: ward`）と1対1で対応する。
- 簡略化で、面積0.01 km2（1万平方メートル）未満の岩礁などの小さな図形はほとんど消える。社人研の1,884地域は、すべて1つ以上の図形を持ち、簡略化の前後で面積の96%以上が残る（詳細は `docs/sources.d/geometry.md`）。
