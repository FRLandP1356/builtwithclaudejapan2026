**加工の内容**（`pipeline/build_areas.py`）

1. 地域は IPSS の「市などの別」が 0（政令市の区、東京23区を含む）・2（その他の市）・3（町村）・9（福島県浜通り地域）の1,884地域。計算の単位はこの地域で、1（政令市の合計）と a（都道府県の合計）は計算しない。
2. 2020年の男女5歳階級別人口（0〜4歳から95歳以上の20区分）を `base`、2025〜2050年の総人口を `official` として取り出した。
3. 生残率・純移動率は期間の始まりの年（2020〜2045年）で、子ども女性比・0〜4歳性比は期間の終わりの年（2025〜2050年）で引き、6期間（2020→25 … 2045→50）の仮定として並べた。
4. 純移動率に値のない13村（檜枝岐村・利島村・御蔵島村・青ヶ島村・粟島浦村・平谷村・野迫川村・下北山村・上北山村・北山村・三島村・座間味村・渡名喜村）は仮定を `null` とし、社人研の2025〜2050年の男女5歳階級別人口を `officialAges` に残した。
5. 地域コードを5桁にそろえた（IPSS は先頭の0を落としている）。小数は有効数字6桁に丸めた。
6. 政令市と区、都道府県と地域の対応は Excel の行の並び（市の行の直後にその区が並ぶ）から作り `groups.json` にした（東京23区はどの政令市にも属さない）。政令市・都道府県の合計は、社人研の合計の行と一致することを確認している。

**生成物**: `public/data/areas/<都道府県コード>.json`（47ファイル）、`public/data/groups.json`、`public/data/index.json`。

**注意**: `official`（2025〜2050年）は社人研の推計値そのもの。2050年より先は、このアプリが社人研の仮定を延ばして出した試算で、社人研の推計ではない。田辺市の2050年は社人研の値が42,309人で、田辺市人口ビジョン案（令和7年1月）の42,311人とは2人違う（このアプリは社人研の値を使う）。

### 加工の内容（`pipeline/build_geometry.py`）

1. N03 は1つの地域が複数の図形（島など）に分かれて入っている。コード（N03_007）が同じ図形を1つにまとめた
2. **社人研の単位に合わせた**：政令指定都市は社人研が区を単位にしているので、区の境界のまま使った（市に統合しない）。東京23区も区のまま。福島県の浜通り13市町村（いわき市・相馬市・南相馬市・広野町・楢葉町・富岡町・川内村・大熊町・双葉町・浪江町・葛尾村・新地町・飯舘村）は1つにまとめ、社人研の「浜通り地域」のコード 07999 を付けた
3. 社人研に地域が無い図形（N03 で村のコードを持つ北方領土の6村、コードの無い所属未定地）は取り除いた。歯舞群島は N03 で根室市に含まれるので残っている。一覧と理由は `docs/geometry-reconcile.md`
4. 名前（`properties.name`）は社人研の名前（`index.json`）にそろえた。コードは5桁の文字列（先頭の0を保つ）
5. mapshaper（`npx mapshaper`）で簡略化した。図形の頂点を残す割合は、県の地図は5%から、全国の県の層は2%から始め、ファイルの大きさの上限（300KB。北海道と沖縄県は600KB）に入るまで段階的に下げた（隣り合う境界は同じ線を共有したまま簡略化し、小さな島も残す）。結果は下の表
6. TopoJSON の座標は、1ファイルごとに縦横それぞれ1万分割の格子に丸めた。1目盛はそのファイルの範囲の1万分の1なので、範囲が広いファイルほど粗くなる。各ファイルの変換値から測った1目盛は、最も粗い東京都（遠い島を含む）で約170m、沖縄県で経度方向約84m・緯度方向約42m、北海道で約57m×46m、小さな県は10m前後以下（滋賀県は約6m×10m）。全国の県の層は約290m×280m
7. 国土数値情報は座標系が JGD2011 で、地図の座標（WGS84 の緯度経度）との差は1m未満のため、座標の変換はしていない

**注意**：この境界は地図表示のための粗い図形で、測量・面積の計算・行政区域の確認には使えない。海岸線と行政界は簡略化しており、実際の境界とは数十〜数百m以上ずれる所がある。
