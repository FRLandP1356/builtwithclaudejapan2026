## 外した項目

- matsushima（松島）: 特別名勝としての松島は松島町以外の市（塩竈市・東松島市）にも及び、単一の地域に確定できない。予備の瑞巌寺（松島町）を採用。 / 分かった所在地: 松島町公式の概要ページ（https://www.town.miyagi-matsushima.lg.jp/page/1312.html）に「日本三景に数えられ、全国有数の観光地で、特別名勝、県立自然公園に指定されています。」。宮城県の特別名勝松島のページ（https://www.pref.miyagi.jp/soshiki/bunkazai/matusima.html）には「県内では、宮城県教育委員会、塩竈市教育委員会及び東松島市教育委員会が管理計画を策定し」と記載。
- tendo-shogi-koma（天童の将棋駒）: 国の伝統的工芸品としての製造地域が天童市以外（山形市など）にも及ぶ可能性があり、単一の市に確定できない。迷ったので外した。 / 分かった所在地: 天童市公式の将棋駒ページ（https://www.city.tendo.yamagata.jp/tourism/shogi/syougikoma.html）に「天童市は、将棋駒の生産量日本一を誇り、生産地では全国で唯一、国の伝統的工芸品に指定され」。伝統的工芸品としての製造地域は、検索結果の要約では天童市、山形市などと記載（公式の伝統的工芸品サイトは取得できず未確認）。
- shosenkyo（昇仙峡）: 指定の所在地が甲府市と甲斐市の2市にまたがる記載のため、1つの市に決められない（指示書の「複数の市町村にまたがるものは載せない」に従い外す）。 / 分かった所在地: 文化遺産オンライン（文化庁）の「御嶽昇仙峡」の所在地欄：山梨県 甲府市平瀬町・高成町・猪狩町、甲斐市
- kumano-kodo-nakahechi（熊野古道 中辺路）: 世界遺産の構成資産「熊野参詣道 中辺路」は、田辺市だけに収まらず上富田町にも資産がある（市町村にまたがる）ため、1つの地域に決められず外す。 / 分かった所在地: 和歌山県の資料（pref.wakayama.lg.jp/prefg/500700/sekaiisan/tsuikatouroku.html）に、中辺路の2016年追加登録として田辺市の「北郡越・長尾坂・潮見峠越・赤木越」と上富田町の「八上王子跡・稲葉根王子跡」の記載。上富田町公式ページ（town.kamitonda.lg.jp/soshiki/shinkou/shoukai/kanko/guide/3025.html）にも「世界遺産「紀伊山地の霊場と参詣道」に追加登録されました」の記載。
- hakata-gion-yamakasa（博多祇園山笠）: 行事のコースが博多区と中央区（福岡市役所前）にまたがり、1つの区に決められないため外した。櫛田神社そのもの（博多区上川端町）を入れる案はある。 / 分かった所在地: 櫛田神社の住所は福岡県福岡市博多区上川端町1-41（博多祇園山笠振興会の公式サイト）。福岡市公式の行事日程では、集団山笠見せ（7月13日）が「呉服町交差点から市役所 2.1km」、追い山笠（7月15日）が「櫛田神社から須崎町 5km」。
- kegon-falls（華厳滝）: 確認は済んだが件数の都合で載せず（予備または上限超過）
