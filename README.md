# 2100年の日本（town-2100）

[English](README.en.md)

テーマは「何を残すか」。対象は、名勝・名物・観光地・食・建物・衣装など、日本らしいもの全体（神社仏閣・遺産・文化・リゾート。テーマパークと温泉地を含む）。日本全体の対象と、各都道府県の対象があります。いま載せているのは各県の代表的な例（名所のデータ220件のうち、表示は201件。名物・食・衣装は未収録）。筋道は、文化→人→生活圏・経済圏→インフラ→費用。文化を残すには人が要り、人がいれば暮らしを支える道や水や医療が要ります。病院や店が成り立たない人口になると、住みたい人が減って流出が速まる、という連鎖の根拠として、暮らしを支える8種の施設（国土交通省の人口の目安）を脇役で見せます。施設そのものは残す対象ではありません。その費用を誰が負担するのかまでを、人口の規模ごとの歳出の実績で見せます。AIには、このアプリの計算を道具として呼ばせ、その結果をもとに答えさせます。

このアプリは、何を残し、何を残さないかを勧めません。決めるための事実を見せるだけで、決めるのは使う人です。

作者の見解：全国の地方が同時に創生すると、人口の面では成り立たない、と作者は考えています。このアプリはその見解の証明ではなく、確かめるための材料を並べたものです。（この文は、作者の発言をもとに Claude が書き、作者が2026年11月6日に確認しました。）

- 試す：https://japan2100.pages.dev （Cloudflare Pages。検索エンジンには載せない設定です）。AIへの質問は、AIの中継（Cloudflare Worker。公開の住所は持たず、公開ページ自身の `/api/chat` から内部で呼ばれます）を通して、本物のモデル（Claude Sonnet 5.5）が答えます。AIの呼び出しには回数の上限があり（1人1日60回、全体で1日400回。上流への呼び出しの回数で、確かめた質問は1つにつき平均2.43回で、全体の400回は約165問分です。日付は UTC で、日本時間の午前9時に切り替わります）、中継の API キーは 2026年12月6日に期限が切れます。

## 3分で触る（審査員の方へ）

公開ページ https://japan2100.pages.dev をそのまま開けます（手元では `npm ci` のあと `npm run dev`。AIの接続先が無いので、自由入力は動きません）。サイトは「1画面に1つのメッセージ」。上のメニュー（名所／地図／答え合わせ／AIに聞く／出どころ）で移ります。

1. **ホーム**：日本の地図が、2025年の実績（国勢調査の確定値 122,972,528人）から2100年の試算へ、6秒で1回だけ動きます（色＝2025年に対する人口の割合、藍の6段階）。点は、残す対象の名所 201件（神社・寺院、世界遺産、文化、リゾート・景勝。テーマパークと温泉地はリゾート・景勝に含みます）。点を押すと名前と「開く」。
2. **名所**（`#/meisho`）：4つの種類と一覧。名所のページ（`#/meisho/<id>`）は、A 場所と100人の並び（1人＝2025年の人口の1%。文化を残すには人が要る）、つながりの全体図（名所→人→暮らしの場→流出が速まる→負担→1人あたりの費用→ほかを残す余力。各ノードにその町の実数。押すと説明へ）、暮らしの場（8種の明かりが人口の目安を下回ると消える。2100年の人口を、実績で直した試算／流出が速まる場合・弱／強で並べる。速まり方はこのアプリの仮定）、働く世代（15〜64歳）の1人が支える人、1人あたりの費用（人口の規模ごとの歳出の実績、令和6年度。いまの町どうしの比較）、ここを残すと（`computeKeep`：目安を保つ人数と、ほかの町で新しく下回る町の数）、公表資料の言葉。下の年のつまみで、全体図と各画面が一緒に動きます。
3. **地図**（`#/chizu`）：日本→県→町。年のつまみと再生、町名・県名の検索はここの1か所。
4. **答え合わせ**（`#/awase`）：(1) 全国の推計と実績、(2) 1,877の町のずれの6段階と県の町ごとの地図、年齢ごとの偏り、(3) 1つの町の線（既定は田辺市。名所のページの町や検索で変わります）。
5. **AIに聞く**（`#/ai`）、**出どころと、数えていないこと**（`#/about`。国防は数えていない、と明記）。

見分け方の約束：実績は濃い実線（塗りの印）、公式推計は細い実線（枠の印）、試算は破線（破線の枠の印）。「予測」とは書きません。名所について残る・残らないは言いません。

## 数字の出どころと確かめ方

**人口の土台**は、国立社会保障・人口問題研究所の「日本の地域別将来推計人口（令和5年推計）」です。2020年の国勢調査を基準に、市区町村ごとに2050年までの人口が公表されていて、計算に使った前提（生残率、純移動率、子ども女性比、0〜4歳の性比）も市区町村ごとに公表されています。2050年より先の、市区町村ごとの公式の推計はありません。

**2025年の実績**は、総務省統計局「令和7年国勢調査 人口等基本集計」（2025年10月1日現在、2026年9月29日公表の確定値、不詳補完値）です。市区町村の男女・5歳階級の人口を、国立社会保障・人口問題研究所の地域に合わせて集計しました（`public/data/actual2025.json`、作り方は `pipeline/build_actual.py`）。全国は 122,972,528人（公式推計の2025年 123,262,450人より 289,922人、0.24%少ない）。浜松市の7つの区は、2024年の区の再編で実績の区分が合わず、公式推計のままです（地図の県の合計は、その分だけ確定値と数千人ずれます）。

**答え合わせ**（`public/data/checks.json`、画面は `#/awase`）は、町ごとの2020年実績・令和5年推計の2025年・2025年実績・平成30年推計の2020年と2025年を並べたものです。実績がある1,877の町のうち、推計より少なかった町が1,206、多かった町が667。ずれは年齢で偏っていて、0〜4歳が推計より7%少なく、15〜24歳が多く、75歳以上が少なくなっていました。

**標準の試算（画面の「実績で直した試算」）**は、2025年の実績の年齢構成を出発点に、社人研と同じ前提で計算し直した系列です（`projectAll(areas, DEFAULT_SCENARIO, 2100, facilities, true, factor)`）。前提のうち、子どもの生まれやすさだけは、2025年の実績が公式の前提を下回っていた水準（全国1つの係数 `observedBirthsFactor`、約0.92倍）のまま続くとしています。高齢の人の亡くなる割合や人の移動のずれは、一時的な出来事の影響を分けられないので、調整していません。係数と系列は `src/site/model.ts` の1か所で作り、全画面が同じものを使います（`STANDARD_SERIES`）。この系列の全国の2100年は、公式の前提を延ばした 6,328万人に対して約5,723万人（2020年の約45%）で、ホームの見出しは、この割合から「半分を下回る／約半分／半分を上回る」を出し分けます。数字は `src/site/model.test.ts` がエンジンの出力と照らして確かめます。

**このアプリの計算**は、その前提を使って自分で計算し直すエンジン（コーホート要因法。5歳ごと・男女別・5年刻み）です。まず、公表されている前提から2050年の公式の結果を再現できることを確かめました（前提が公表されている1,871地域）。

| 年 | 地域ごとの人口のずれ：中央値 | 90%の地域が収まる幅 | 最大 |
|---|---|---|---|
| 2025年 | 0.0039% | 0.042%以内 | 0.705% |
| 2030年 | 0.0041% | 0.051%以内 | 0.995% |
| 2040年 | 0.0049% | 0.057%以内 | 0.841% |
| 2050年 | 0.0053% | 0.076%以内 | 1.39% |

2050年は、99.47%の地域が0.5%以内に収まります。全国の合計は、このアプリが104,686,401人、公式が104,686,386人（1,884地域の合計。前提が公表されていない13村は、公式の年齢別人口をそのまま使っています）。表の値と合計は、コミット ca909ba で測り直した値です（計算エンジンは fa21f09 から変わっていません）。テストが毎回確かめるのは、2050年のしきい値だけです（2050年の中央値が0.01%以内、98%以上の地域が0.5%以内、最大が2%以内、全国の合計が公式との差1,000人以内でなければ失敗します）。数字を確かめた経緯は [docs/dev-log.md](docs/dev-log.md) にあります。

このアプリの2050年までの数字は、国立社会保障・人口問題研究所が発表した値と、町では数人（テストが全1,884地域で確かめた最大は10人未満）、都道府県では数十人（100人未満）ほど違うことがあります。たとえば田辺市の2050年は、国立社会保障・人口問題研究所の表では42,309人、このアプリの計算では42,311人です。町の詳細の「人口の推移の数字を表で見る」を開くと、表の下に同じ注記が出ます。

**2050年より後**は、既定では、2045→2050年の期の前提を据え置いて延ばします。全国の2100年は 63,279,524人（6,328万人）で、国立社会保障・人口問題研究所が別に公表している長期の参考推計（2071〜2120年。出生中位・死亡中位で2100年は6,278万人）と近い値です。前提は画面で変えられます。

| 2100年の全国の人口 | このアプリの試算 |
|---|---|
| 前提を据え置く（既定） | 6,328万人 |
| 人口の移動が2100年に向けて止まる | 5,852万人 |
| 子どもの生まれやすさ 1.2倍 | 7,093万人 |

人口の移動が止まると、全国の合計は減りますが、人口が減りつつある小さな町では、転出も止まるので、かえって多くなることがあります（田辺市は2100年に1.19万人が1.37万人）。

### 数字の限界

- AIに聞く（`#/ai`）の計算は、公式の前提を延ばした試算（2020年の国勢調査から）のままで、サイトの標準の試算（2025年の実績から計算し直し、出生のずれを先にも当てはめたもの）には未統一です。数字が少し違います。
- 2050年より後は、予測ではなく、前提を置いた計算です。小さな町ほど、前提の影響が大きく出ます。
- 前提が公表されていない13の村（檜枝岐村、利島村、御蔵島村、青ヶ島村、粟島浦村、平谷村、野迫川村、下北山村、上北山村、北山村、三島村、座間味村、渡名喜村）は、2050年まで公式の値を使い、それ以降は同じ県の変化率で延ばします。この村に印を付ける表示は、この版の画面にはまだありません。
- 基準は2020年の国勢調査と、2020年ごろの市区町村の区域です。合併などで境界が変わっても反映しません。
- 地図の境界は、表示用に簡略化した粗い図形です（測量・面積・行政区域の確認には使えません）。海岸線と行政界は、数十〜数百m以上ずれる所があります。0.01平方キロメートル未満の小さな岩礁はほとんど描かれません。
- 北方領土の6村（色丹村、泊村、留夜別村、留別村、紗那村、蘂取村）は描いていません。国立社会保障・人口問題研究所にその数字が無いためで、領土についての見解を示すものではありません。歯舞群島は国土数値情報で根室市に含まれているので、根室市の図形に入っています。

**製品の中で**（公開ページで動いています。作りと、テストと本物のモデルで確かめた範囲を書きます）：「AIに質問」は、Anthropic の API（モデル `claude-sonnet-5-5`）を、小さな Cloudflare Worker 経由で呼びます。API キーは Worker の秘密としてだけ置き、リポジトリにも、画面側（ブラウザ）にも出しません（作成のとき、作成画面を操作したブラウザの一時ファイルに値が写り、削除しました。[docs/dev-log.md](docs/dev-log.md) の6.2）。

- Claude は、次の9つの計算の道具を呼んで答えます。道具の名前・説明・入力の形は、Worker の側で決めたものだけが使われ、画面から送られた値は使いません。

  2. `get_series`：地域の人口の推移（65歳以上の人数と割合も）
