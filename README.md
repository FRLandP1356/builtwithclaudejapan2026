# 2100年の日本（town-2100）

[English](README.en.md)

2100年までの日本の人口を、地図で見るアプリです。日本、都道府県、町の順に絞り込み、町ごとの人口と年齢の構成、その人口が施設ごとの「人口の目安」を上回るか下回るかを見られます。人口を地域のあいだで割り振り直すと何が変わるかも見られ、AIには、このアプリの計算を道具として呼ばせ、その結果をもとに答えさせます。

このアプリは、何を残し、何を残さないかを勧めません。決めるための事実を見せるだけで、決めるのは使う人です。

作者の見解：全国の地方が同時に創生すると、人口の面では成り立たない、と作者は考えています。このアプリはその見解の証明ではなく、確かめるための材料を並べたものです。（この文は、作者の発言をもとに Claude が書いたもので、文言は作者の確認待ちです。）

- 試す：https://japan2100.pages.dev （Cloudflare Pages。検索エンジンには載せない設定です）。AIへの質問は、AIの中継（Cloudflare Worker、https://town-2100-api.your-account.workers.dev ）を通して、本物のモデル（Claude Sonnet 5.5）が答えます。AIの呼び出しには回数の上限があり（1人1日60回、全体で1日400回。上流への呼び出しの回数で、確かめた質問は1つにつき平均2.43回で、全体の400回は約165問分です。日付は UTC で、日本時間の午前9時に切り替わります）、中継の API キーは 2026年12月6日に期限が切れます。
- 状態：ハッカソンの提出前。画面と AI の中継は 2026年11月6日に公開し、本物のモデルで動くことを確かめました（結果と、確かめていないことは[限界と未完了](#限界と未完了)と [docs/ai-live-check.md](docs/ai-live-check.md)）。AIの保存済みの答え5件は、作者が全文を読んで承認しました（`verified`、2026年11月6日）。画面は、質問の例のボタンを押したときと、AIに接続できないときに、これを出します。この文書の数字（コミットの数、テストの件数など）は、コミット a15e934（2026-11-06）の時点のものです。
- リポジトリ：提出まで非公開です。提出の時点で公開にします。
- デモ動画：提出フォームにリンクを書きます（置き場所は未定。約3分、日本語、合成音声のナレーションと字幕。公開ページを録画したもので、このリポジトリには入っていません）。

## 3分で触る（審査員の方へ）

公開ページ https://japan2100.pages.dev をそのまま開けます。手元でも動かせます（[動かす・試す・作る](#動かす試す作る)。`npm ci` のあと `npm run dev`。この場合はAIの接続先が無いので、6.のAIへの自由入力は動きません。質問の例のボタンは、保存済みの答えを出します）。

1. **日本の地図**：開くと2050年（社人研の公式推計の最後の年）が出ます。都道府県ごとに色が付きます。色は2020年に対する増減で、減るほど赤茶、増えると青です。2100年まで見るには、下の年のスライダーの再生ボタン（▶）を押すか、スライダーを動かします。2020年から2100年まで、5年刻みです。
2. **県から町へ**：県を押すと、その県の市区町村の地図に変わります。町の名前の検索もできます。政令指定都市と東京23区は、区ごとに表示します。
3. **町の詳細**：町を押すと、人口の推移（公式の推計は実線、このアプリの試算は破線）、5歳ごと・男女別の人口ピラミッド、65歳以上と0〜14歳の割合、施設ごとの「人口の目安」との比較が出ます。施設は48種類で、このアプリが必須として扱う8種類（飲食料品小売業、郵便局、銀行（中央銀行を除く）、一般診療所、介護老人福祉施設、一般病院、通所・短期入所介護事業、訪問介護事業）を先に、残りは折りたたんで出します。画面に出る施設の名前は `public/data/facilities.json` の名前と同じです（AIの文章は Claude が書くので、言い方が違うことがあります）。町の人口を各施設の目安に当てはめた結果は、「人口の目安を上回る」「境目」「人口の目安を下回る」の3つで出ます。
4. **前提を変える**：2050年より後の計算に使う前提を動かします。子どもの生まれやすさ（2050年の水準の0.6〜1.4倍）、人口の移動（2050年ごろの傾向を続ける、または2100年に向けて少しずつ止まる。強さは0〜1.5倍）、インフラ連動の過疎の加速（なし・弱い・強い）。地図と数字がその場で変わります。2050年までの数字は、どう動かしても変わりません。
5. **人口の割り振り**：全国の人口を変えずに、ある県や町の人口を増やす（または減らす）と、ほかの地域がどう変わるかを計算します。試し方：(1) 年のスライダーを2100年に合わせる。(2) 「人口の割り振り」の「人口を増減させる地域」で和歌山県を選ぶ（何も選んでいない時は、はじめから和歌山県です。増やす割合の初期値は10%）。(3) 「地図に反映する」を押す。地図の色が、割り振りによる人口の変化に変わります。和歌山県の人口が10%（約2.6万人）増えると、ほかの地域が合わせて同じ人数だけ減ります。そのとき高野町は470.6人から517.7人になり、人口500人という目安を下回らなくなります。500人を目安とする施設は8つです（「飲食料品小売業」「飲食店」「酒場、ビアホール」「旅館、ホテル」「郵便局」「一般診療所」「歯科診療所」「介護老人福祉施設」）。この500人は、元の表で「0〜1,000人」の区間の中央の値を使ったもので、実際に観測された境目ではありません。人口の差は全国で見ると小さいので、施設ごとに、人口の目安を下回らなくなる町と、下回る町の数がどう変わるかで見せています（この例では、48施設のうち12施設の町の数が変わります）。表の施設名を押すと、その施設で目安をまたいだ町が、県の地図では輪（青の実線が「人口の目安を下回らなくなる町」、赤茶の破線が「人口の目安を下回る町」）、全国の地図では県ごとの印（「+n −n」）で示されます。割り振りを消すには、割り振りが地図にある間に出る「割り振りを地図から消す」を押すか、Esc キーを押します（Esc は、文字を入れる欄や選択欄にいる間は効きません）。
6. **AIに質問**：画面の「AIに質問」に、日本語で質問を入れて送ります（200文字まで）。質問の例のボタン（5つ）を押しても、同じように質問が送られます。本物のモデル（Claude Sonnet 5.5）が、このアプリの計算を道具として呼び、その結果から答えます。答えの下の「使った道具と数字」を開くと、どの道具に何を渡し、何が返ったかを確かめられます。

   使うときに見込んでおくこと：
   - 答えが出るまで、ふつうおよそ5〜15秒かかります（短い質問は、もっと早く返ります）。道具を呼ぶ質問では、中継（Worker）への呼び出しが2〜4回（道具を使わない質問は1回）になります。確かめた95回の質問では、中継の応答時間の合計が2.9〜12.2秒（中央値5.6秒）で、画面では通信と計算の時間が加わります。デモ動画の録画で見た2回は、約9秒でした。待っている間は「計算の結果を引いています…」と出ます。
   - 同じ質問でも、答えの文面は毎回同じとは限りません。モデルがそのたびに書くためです。答えの数字は、道具の結果と照らし合わせています（範囲と限界は「Claude をどう使ったか」）。2050年までの町の数字は、このアプリの計算値で、社人研の表と数人違うことがありますが、AI の答えは「社人研の公式推計」と書くことがあります。
   - 保存済みの答え（質問の例に、あらかじめ本物のモデルに答えさせた答えを、中継なしで即座に出すもの）は5件あり、作者が全文を読んで承認しました（2026年11月6日、`verified`）。質問の例のボタンを押すと（同じ文を会話の最初の質問として送っても）、中継を呼ばずに、「保存済みの回答」の印と「あらかじめ保存した回答です…」の注記つきで、すぐに出ます（`public/data/cached_answers.json`）。分かっている限界が2つあります。田辺市の答えは、2050年の人口 42,311人を「社人研の公式推計」と書いていますが、社人研の表の値は 42,309人で、42,311 はこのアプリの計算値です。和歌山県の割り振りの答えは、道具が減る地域を返さないので、どの地域が減るかは答えていません。どちらもファイルの note に書いてあります。
   - 回数の上限（1つのIPで1日60回、全体で1日400回。上流への呼び出しの回数です。確かめた95回の質問は、1つにつき平均2.43回の呼び出しでした（確認用の質問の平均で、1つの質問は最大9回になりえます）。この平均なら、全体の400回は約165問分、1人の60回は約25問分です。ほかに、1つのIPで60秒に20回まで）に当たったとき、または中継に届かないときは、その質問に保存済みの答えがあれば、それを「いまはAIに接続できないため、保存済みの答えを表示しています。」の注記つきで出します。無いときは、「いまはAIに接続できません。保存済みの質問を試してください。」と出て、5つの保存済みの質問のボタンが並びます。
   - 手元で `npm run dev` で動かしたときなど、AIの接続先を決めていないビルドでは、パネルが最初の説明文で、先に「このバージョンでは、AIへの質問は使えません（AIの接続先がまだ用意されていません）。地図、数値、前提の調整、人口の割り振りはそのまま使えます。」と言います。質問の例のボタンは保存済みの答えを出しますが、自由入力は、同じ文のカードが出るだけで、答えは出ません（[docs/ai-endpoint.md](docs/ai-endpoint.md)）。公開ページは、AIの接続先を決めてビルドしたものです。

見分け方の約束：2050年より後の数字には、必ず「試算」の印が付き、グラフでは破線になります。「予測」とは書きません。2050年までは「公式推計」、2020年は「実績（国勢調査）」と出ます。割り振りを地図に出している間、2050年までの年で割り振りによって変わった数字は、公式の値ではなくこのアプリの計算なので、見出しに「公式推計」の代わりに「割り振り後」の印と「公式推計をもとにこのアプリが計算」という注記が付きます。AIの答えのカードも同じで、2050年より後の年を示す答え（見分けがつかないときは、示すものとして扱います）には、「試算」の印と「2050年より後は、このアプリの試算です（予測ではありません）」の注記を付けます。

地図はキーボードでも使えます。Tab で地図に入ると、止まる場所は地図ごとに1つです（地図の手前に「地図をとばして、年の選択へ」というリンクが出ます）。矢印キーで、その向きの隣の地域へ、PageUp と PageDown で前と次の地域へ、Home と End で最初と最後の地域へ移り、Enter か Space で選びます。PageUp・PageDown を使えば、矢印では届かない地域も含めて、すべての地域に着けます（全国の地図と47の県の地図で、テストが確かめています）。

## 数字の出どころと確かめ方

**人口の土台**は、国立社会保障・人口問題研究所（社人研）の「日本の地域別将来推計人口（令和5年推計）」です。2020年の国勢調査を基準に、市区町村ごとに2050年までの人口が公表されていて、計算に使った前提（生残率、純移動率、子ども女性比、0〜4歳の性比）も市区町村ごとに公表されています。2050年より先の、市区町村ごとの公式の推計はありません。

**このアプリの計算**は、その前提を使って自分で計算し直すエンジン（コーホート要因法。5歳ごと・男女別・5年刻み）です。まず、公表されている前提から2050年の公式の結果を再現できることを確かめました（前提が公表されている1,871地域）。

| 年 | 地域ごとの人口のずれ：中央値 | 90%の地域が収まる幅 | 最大 |
|---|---|---|---|
| 2025年 | 0.0039% | 0.042%以内 | 0.705% |
| 2030年 | 0.0041% | 0.051%以内 | 0.995% |
| 2040年 | 0.0049% | 0.057%以内 | 0.841% |
| 2050年 | 0.0053% | 0.076%以内 | 1.39% |

2050年は、99.47%の地域が0.5%以内に収まります。全国の合計は、このアプリが104,686,401人、公式が104,686,386人（1,884地域の合計。前提が公表されていない13村は、公式の年齢別人口をそのまま使っています）。表の値と合計は、コミット a15e934 で測り直した値です（計算エンジンは fa21f09 から変わっていません）。テストが毎回確かめるのは、2050年のしきい値だけです（2050年の中央値が0.01%以内、98%以上の地域が0.5%以内、最大が2%以内、全国の合計が公式との差1,000人以内でなければ失敗します）。数字を確かめた経緯は [docs/dev-log.md](docs/dev-log.md) にあります。

このアプリの2050年までの数字は、社人研が発表した値と、町では数人（テストが全1,884地域で確かめた最大は10人未満）、都道府県では数十人（100人未満）ほど違うことがあります。たとえば田辺市の2050年は、社人研の表では42,309人、このアプリの計算では42,311人です。町の詳細の「人口の推移の数字を表で見る」を開くと、表の下に同じ注記が出ます。

**2050年より後**は、既定では、2045→2050年の期の前提を据え置いて延ばします。全国の2100年は 63,279,524人（6,328万人）で、社人研が別に公表している長期の参考推計（2071〜2120年。出生中位・死亡中位で2100年は6,278万人）と近い値です。前提は画面で変えられます。

| 2100年の全国の人口 | このアプリの試算 |
|---|---|
| 前提を据え置く（既定） | 6,328万人 |
| 人口の移動が2100年に向けて止まる | 5,852万人 |
| 子どもの生まれやすさ 1.2倍 | 7,093万人 |
| 子どもの生まれやすさ 0.8倍 | 5,634万人 |
| 移動が止まり、1.2倍 | 6,506万人 |

人口の移動が止まると、全国の合計は減りますが、人口が減りつつある小さな町では、転出も止まるので、かえって多くなることがあります（田辺市は2100年に1.19万人が1.37万人）。

**インフラ連動の過疎の加速**は、このアプリが加えた仮定です。公式の前提は、病院や店の有無と転出を結び付けていません。この仮定は「必須の施設が人口の目安を下回ると、その町から出る人が増える」と置いた計算で、どれだけ増えるかを測った根拠はありません。幅を見るための仮定で、初期はオフです。

**施設の「人口の目安」**は、国土交通省国土政策局の表「サービス施設の立地する確率が50%及び80%となる自治体の人口規模（三大都市圏を除く）」です。ある人口規模の自治体のうち、その施設が1つでもある自治体の割合が50%（p50）・80%（p80）になる人口規模です。2009〜2012年の統計で、三大都市圏（埼玉・千葉・東京・神奈川・岐阜・愛知・三重・京都・大阪・兵庫・奈良の11都府県）を除いて集計されています。画面では、町の人口を施設ごとに、50%の人口規模を下回る「人口の目安を下回る」、50%以上80%未満の「境目」、80%以上の「人口の目安を上回る」のどれかで出します（50%と80%の値が同じ施設に「境目」はありません）。これは目安であって、施設の閉鎖の予告ではありません。三大都市圏の町には表の対象外と注記して、参考として出します。

### 数字の限界

- 2050年より後は、予測ではなく、前提を置いた計算です。小さな町ほど、前提の影響が大きく出ます。
- 施設の目安は、2009〜2012年の統計です。人口が同じでも、いまの施設の有無とは一致しません。
- 前提が公表されていない13の村（檜枝岐村、利島村、御蔵島村、青ヶ島村、粟島浦村、平谷村、野迫川村、下北山村、上北山村、北山村、三島村、座間味村、渡名喜村）は、2050年まで公式の値を使い、それ以降は同じ県の変化率で延ばします。この村に印を付ける表示は、この版の画面にはまだありません。
- 基準は2020年の国勢調査と、2020年ごろの市区町村の区域です。合併などで境界が変わっても反映しません。
- 地図の境界は、表示用に簡略化した粗い図形です（測量・面積・行政区域の確認には使えません）。海岸線と行政界は、数十〜数百m以上ずれる所があります。0.01平方キロメートル未満の小さな岩礁はほとんど描かれません。
- 北方領土の6村（色丹村、泊村、留夜別村、留別村、紗那村、蘂取村）は描いていません。社人研にその数字が無いためで、領土についての見解を示すものではありません。歯舞群島は国土数値情報で根室市に含まれているので、根室市の図形に入っています。

## Claude をどう使ったか

**開発で**：このリポジトリのコードは、作者の申告では、すべて Claude Code（コマンドラインの Claude）が書いたものです（この申告は、作者の確認待ちです。下の「Claude が作った部分と、人が決めた部分」を参照）。コミットは、ハッカソンの期間中の2026年11月5日と6日に入れました（最初の作業のコミットは11月5日 06:19。リポジトリの外の試作と調べものは、それより前です。これとは別に、2026年10月24日のコミットが1件あります。下の「既存の素材」）。データ、計算エンジン、地図と画面、AIと中継の流れを、別々の git worktree（書き込む場所を分けた作業用の複製）で並列に進め、タスクごとに、実装した Claude とは別の Claude のセッション（同じ系統のモデル）がレビューしました。人によるレビューでも、他社の AI によるレビューでもありません。判断・指摘・修正の記録は「台帳」に残してありますが、台帳、タスクの指示書と報告書、設計書、実装計画、画面のスクリーンショットは、このリポジトリには入れていません（ここからは読めません）。以下の数字は、コミット a15e934 の時点で、台帳・報告書・git から数え直したものです。

- 実装のタスク：17（データ作り、計算エンジン、施設の表、境界の図形、中継、AIの道具、画面の骨組みと地図、町の詳細、前提と割り振りの画面、AIの画面、割り振りの地図表示、文書）
